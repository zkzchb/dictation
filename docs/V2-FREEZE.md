# Dictation V2.0.0 冻结说明

> 本文记录 `v2.0.0` 标签的历史发行事实。v2.1 起程序与正式内容分仓，当前部署说明以
> 根目录 README 和部署文档为准。

V2.0.0 是听写、间隔复习、批量录音、集中质检和批量重录流程的稳定功能基线。
冻结后停止向 V2 增加新功能，只接受数据安全、严重兼容性和安全漏洞修复；后续产品
形态从该标签继续演进。

## 冻结边界

- 43 门课程、814 个知识点；
- 869 个词条音频和 25 个系统提示音；
- SQLite 学习数据与真人录音/质检台账分层保存；
- 提交幂等、原子状态写入、上传校验、备份和健康检查；
- Ubuntu 24.04、Python 3.12、systemd 与 Caddy 部署基线；
- `main` 为标准联网发行，`main-offline` 为相同应用提交的离线增量发行。

教材 JSON 和标准 TTS 是产品数据，两条发行线都包含。Python wheelhouse 只进入
`main-offline`，成品压缩包只进入 GitHub Release。

## 已完成验收

- GitHub CI：Python 编译、回归测试、浏览器脚本解析、依赖审计；
- 全新 Ubuntu 24.04 VPS 从空白状态安装；
- 43/814 空白数据库初始化；
- 894 个标准音频逐文件校验；
- systemd、Caddy、IP HTTP 入口和应用健康检查；
- 当前 BCE 环境通过公网 IP 完成访问。

域名 HTTPS 因云厂商备案流程暂缓，属于外部部署条件，不改变已经冻结的应用代码。
备案完成后重新运行安装入口启用 HTTPS，并补记域名验收结果。

## 版本标签

- `v2.0.0-rc.1`：BCE 离线安装候选快照；
- `v2.0.0`：标准 `main` 功能冻结标签；
- `v2.0.0-offline.1`：与 `v2.0.0` 对应的第一版离线依赖修订。

## 维护规则

1. 所有功能和安全修复先进入 `main`；
2. 通过全部 V2 检查后再同步到 `main-offline`；
3. 离线分支只允许修改 wheelhouse、离线入口、离线文档和发行元数据；
4. 每次离线发行都必须校验 wheel 文件集合、SHA-256、CPU 架构和 `pip check`；
5. 升级和回滚按 `V2-UPGRADE-AND-ROLLBACK.md` 执行。
