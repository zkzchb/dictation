## 架构决策：程序与内容分仓

公开后不再建立一份去除历史的新程序仓库。现有仓库保留真实提交与 PR 记录，并在 v2.1
完成一次清晰的产品边界收敛：

1. `dictation` 是程序仓库，只维护 V2（FastAPI/SQLite）和 V3（Cloudflare Workers/D1）。
2. V1 从当前产品线退出；`v2.0-stable` 与已有标签继续提供旧部署回滚能力。
3. `dictation-content` 是内容仓库，保存自制教材包、本人录制的词条与系统提示音，并按
   自己的版本节奏持续增加教材。
4. 两个仓库通过 content-pack v1 契约组合，而不是通过复制代码、固定目录或课程号耦合。
5. 程序发布冻结后，只要 content-pack schema 仍兼容，内容仓库可以独立新增或修订教材包。
