# Dictation v2.1 OSS 路线图

本文件是 v2.1 的规范性路线图。短期目标是把已经冻结的 v2.0.0 整理为一个可信、
可复现、便于贡献的公共开源项目，并以 v2.1.0 申请 Codex for Open Source。

## 发布原则

1. `v2.0-stable`、`v2.0.0` 和 `v2.0.0-offline.1` 保持不变，继续作为现有部署的
   可回滚基线。
2. v2.1 只在 `codex/v2.1-oss` 开发；达到候选版门槛后才合并主线。
3. 程序代码、教材数据、生成音频和用户数据分别定义来源、许可与分发边界。
4. Ubuntu 本地、Ubuntu VPS/BCE 和 Cloudflare Workers 三个目标使用同一内容包规范，
   但可以保留各自适合的运行时实现。
5. 每个发布结论都必须有自动化检查或真实部署记录支持。

## OSS 产品边界

v2.1 的公共产品定位为“可自托管、内容包驱动的中文听写练习系统”。核心仓库提供：

- 听写、复习、错词回流和多音字轮换引擎；
- SQLite 与 Cloudflare D1 两种数据层；
- 浏览器端练习、录音、质检和批量重录界面；
- 内容包校验、导入、音频生成与迁移工具；
- 本地、VPS 和 Cloudflare 的可复现部署流程；
- 一个完全独立编写、许可清楚的小型演示内容包。

第三方教材词表、根据第三方教材整理的数据、TTS 服务生成物和用户真人录音不因程序
采用 AGPL-3.0 就自动取得同一许可。权利基础没有确认的内容不得进入 v2.1 公共发行物。

- [x] `v2.0-stable` 指向 v2.0.0 冻结提交 `e0b9e255`。
- [x] v2.0.0 标准版与离线修订版已经发布。

### G2：内容包化

- [ ] 以 `dataset.json` 为入口定义 content-pack v1 schema。
- [ ] 移除运行时代码中的 `chinese/3a`、固定课程号和固定数量依赖。

- [ ] 重写 README：项目定位、截图、架构、五分钟试用、三种部署和路线图。

### G4：三目标验收

- [ ] 全新 Ubuntu 24.04 本地安装、启动、练习、录音、重启与卸载。

- [ ] 保存命令、版本、时间和结果，但不保存凭据或个人服务器地址。

### G5：发布与申请

- [ ] 发布 `v2.1.0-rc.1`，完成候选版安装验证并修复阻塞问题。
- [ ] 发布 `v2.1.0`，生成发布说明、校验和、SBOM 与部署证据。

      后续维护计划。

## 完成定义

只有同时满足以下条件，v2.1 才能标记为正式版：公共仓库不含未解决的敏感信息或
权利不清内容；演示内容可以从空白环境独立运行；三个部署目标至少各有一次可复现的
成功记录；CI 与依赖审计通过；升级和回滚经过真实验证；公开文档足以让没有项目背景的
贡献者完成安装、测试和第一个 Pull Request。
