## 1. 两种听写模式

| 模式 | 适用课程 | 听写词数 | 附加 |
|---|---|---|---|
| **生字听写** | 正式课（lid 末位非 0），34 门 | **30 词** | + **2 个多音字自主默写** |
| **单元复习** | 单元复习课（lid 末位为 0），8 门 | **50 词** | 无 |

多音字自主默写不计入 30 词，作为独立段落放在听写末尾。

## 2. 生字听写：选词梯队

按顺序取词，去重后累计达到 30 即停止。

| 梯队 | 内容 | 取法 |
|---|---|---|
| **1** | 上一次听写的错词 | **全部**，无条件保底 |
| **2** | 本课词语表（vocab） | 全部 |
| **3** | 本课生字表（word2write） | 全部，每字取 1 个组词 |
| **4** | 前 2–4 次听写的错词 | 按错误次数降序补充 |
| **5** | 前 1–3 课的生字表 | 每字取 1 个组词 |
| **6** | 前 1–3 课的词语表 | 全部 |
| **7** | 继续向前回溯（可跨单元） | 直至凑满 30 |

**冷启动**：lesson 3111（开学第一课）本课只有 23 词，此时无任何错词与前序课程，从 lesson 3000（总复习）取 10 组易混字（20 词）补足。自 3112 起本学期资源已足够，3000 不再回捞。

### 实测：零错词最坏情况下的满足梯队

| 满足于 | 课数 |
|---|---|
| 梯队 3（本课词语 + 生字即够） | 2 门（3161、3173） |
| 梯队 5（+ 前 3 课生字） | 20 门 |
| 梯队 6（+ 前 3 课词语） | 10 门 |
| 梯队 7（需再回溯一课） | 2 门（3132 犟龟、3133 小狗学叫） |

3132 / 3133 是连续略读区，自身零词、前两课也零词，实际只从 3131 拿到 26 词，再回溯到 3123 即超过 30。这是零错词的理论最坏值；真实使用中第 12 课时错词表已积累，梯队 1、4 即可补足，不会走到梯队 7。

### 略读课与语文园地

11 门课自身零生字零词语（3113、3114、3124、3125、3132、3133、3143、3153、3164、3165、3184）。这些课的 30 词**全部来自前序课程复习**，属预期行为——没有新词就复习旧词，不跳过听写。

## 4. 多音字自主默写（每次 2 个）

多音字**不进听写**——听写是"听音写字"，而多音字的难点在"同字不同音"，报音就等于给了答案。改为末尾独立段落：

> 「请根据多音字的不同读音组词。第一个：**好**」

学生自己写出该字各读音对应的词并标注拼音，不限于词库里的参考例词。这也是每个多音字只占 1 个指标的原因。

**取字规则**：优先取本课多音字；本课不足 2 个时，从前序课程已学的多音字中回溯补足。词库现状：39 组多音字，其中 13 组在 lesson 3000（冷启动），其余分布在 20 门正式课，每课 1–3 组。

---

## 5. 通用约束

- **一次听写内不出现重复词**：生字表与词语表同课撞词时（实测 118 处，涉及 20 课），优先取该生字的另一个组词；两个组词都撞则该生字不单独出题，由词语表那条覆盖。
- **一个生字一次只出 1 个组词**：另一个留作后续复习或补测时换用。这条规则是每课可选词量的决定因素。
- **易混字成对出现**：typo 表的形近字对（如「原来 / 队员」「积水 / 织布」）必须同次出现，且中间至少隔开 3 个词，否则学生靠语音对比即可猜出。
- **内容不超纲**：所有词均来自当前课或已学过的课，不引入未学内容。

---

## 6. 实现口径（给程序）

```
输入: lid（目标课）, date, mode
输出: words[N], polyphonic[2]

N = 50 if lid.endswith('0') else 30

若 mode == 生字听写:
    梯队 = [
      上次错词(全部),
      本课vocab, 本课w2w(每字1词),
      前2-4次错词,
      前1-3课w2w(每字1词), 前1-3课vocab,
      继续回溯(不限课数, 可跨单元)
    ]
    lid == 3111 时在梯队4位置插入 lesson3000 易混字
else:  # 单元复习
    unit = lid[:3]
    kids = [l for l in 正式课 if l.startswith(unit)]
    梯队 = [
      本单元错词(全部),
      kids的vocab + kids的w2w,
      本复习课typo(tw1+tw2) + 本复习课vocab
    ]

逐梯队取词 → 去重 → 累计达 N 停止
应用约束: 同字冲突换组词 / 易混对间隔≥3 / 不超纲
多音字: 本课polyphonic优先, 不足2个向前回溯
```
